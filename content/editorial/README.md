## Reproduction

Run `npx tsx scripts/build-reading-canon-v2.ts` to rebuild the draft from the four suit files and major-arcana entries. Use `--check` to verify the generated bytes without writing them. Generate a fresh review packet with `npm run content:activate -- --review-packet --bundle content/reading-canon-v2-draft.json --out <new-file>`; the command refuses to overwrite an existing review artifact. It does not approve or activate content.
